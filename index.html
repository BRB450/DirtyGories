Guttergories

A dirty twist on Scattergories. 😈

📜 View Guttergories Rules
  • The Letter: A random letter is chosen each round. All answers must begin with that letter. Ignore articles like “The,” “A,” or “An.”
  • The Categories: Everyone uses the same list. One answer per category, starting with the round’s letter.
  • The Timer: You must finish your answers before the timer runs out. No changes after time ends.
  • Scoring:
    • 🟢 Unique answer: 10 points
    • 🟡 Matching answer: 5 points
    • 🔴 Blank answer: 0 points
    • 🌟 Alliteration bonus: +1 point per matching letter (up to 3)
    • Example: “Sexy Slippery Snakes” = 10 + 3 = 13 points
  • Voting: If an answer is disputed, the group votes. Majority rules.
